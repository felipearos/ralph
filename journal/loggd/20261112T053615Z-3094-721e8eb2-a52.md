## What the iteration was actually worth: the body was aiming the coder at the wrong function

The ticket's `What to build` spends a whole paragraph on how "reusing `discoverBooks` as it stands would smuggle two things back in". **The v1 books read has never called `discoverBooks`.** `src/app/api/v1/books/browse/route.ts:34` calls `getPopularBooksPage` (`src/lib/hardcover.ts:293-315`), and #3065 — the blocker, in flight on `origin/ralph/3065-books-browse-filters` — renames it `getBookBrowsePage` and is the ticket that composes the genre, decade and sort conditions. Cloning `discoverBooks` would have got three things wrong:

- **the genre index.** `getBookBrowsePage` uses `cached_tags: { _contains: $genre }` with `{ Genre: [{ tag }] }`; `discoverBooks` uses `taggings: { tag: { tag: { _eq: $genreTag } } }`. The catalog's `tag` field is documented against the curated `cached_tags.Genre[]`, so `discoverBooks` is the wrong one.
- **AC4, which the right function already satisfies.** `getBookBrowsePage` asks `limit + 1` with no `books_aggregate`, every `BOOK_BROWSE_ORDER` literal ends `{ id: asc }`, and it returns `rowCount: rows.length` over `rows = data.books.slice(0, limit)` with `filterOutSummaries(rows)` after. That is *exactly* AC4's "rows kept on the page, look-ahead trimmed, before summaries are dropped" — `page.offset + pageIds.length` at `users/books/route.ts:55-56`. Extend it and the cursor is free; clone `discoverBooks` and you reimplement it.
- **AC3's floors are three sites, not four, and one is unconditional.** `where.push(readerFloor ? "users_count: { _gte: 25 }" : "users_count: { _gt: 0 }")` is two of the body's four floors in one line and **always emits one of them**, so "not applied within a shelf" is a new third state, not a skipped branch.

## The open question I flagged rather than decided

`BOOK_BROWSE_ORDER.newest` is `"[{ release_year: desc }, { id: asc }]"` — plain `desc`, nulls-first in Hasura. In the popular grid the current-year clamp always adds `release_year: { _lte: $toYear }` for `newest`/`oldest`, which excludes null years. **AC3 drops that clamp inside a shelf**, so sorting your own Read shelf by Newest First would open on every book Hardcover has no release year for. No documented rule says how an undated book sorts, so the comment states a default (`desc_nulls_last`/`asc_nulls_last` on the shelf path only, #3065's literals untouched, with a null-year fixture asserting it) and names it as Felipe's call rather than mine. Round 2 found this; it would have shipped.
