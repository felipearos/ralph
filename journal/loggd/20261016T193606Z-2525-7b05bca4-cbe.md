## What changed

`getUserExternalStatusList` (`src/server/queries/externalStatus.ts`) is the single read behind all
four of the books read / want-to-read and music listened / wantlist lists. It paged with
limit/offset while ordering by `updated_at` alone, so rows written in the same instant (a bulk
import) could repeat across pages or be skipped entirely. The order now ends on
`table.external_id`, which `unique(user_id, external_id, media_type)` already makes unique inside a
read filtered on `user_id` and `media_type`. No migration, no index, no signature change; the
`readStatus.ts` / `listenStatus.ts` adapters needed no edit because every list goes through this
one function.

New `src/server/queries/externalStatus.list-paging.integration.test.ts` pages 25 same-timestamp
rows 7 at a time across both tables and both predicates.

## Key decisions

- **AC2's "fails with the tie-breaker removed" is carried by the order assertion, not the
  repeat/skip ones.** With `.orderBy(table.updated_at)` restored, PGlite's heap order was stable
  enough that the `Set` and set-equality checks still passed; only
  `expect(collected).toEqual(sorted(BOOK_IDS))` failed. The spec reviewer ruled that meets the
  criterion as written — three properties joined by "and", with no claim about which assertion must
  break — and the PR body says so plainly. Observing a real repeat would likely need a backend
  other than PGlite.
- The orchestrator re-ran the mutation check itself rather than trusting the executor's report.
- Kept limit/offset rather than moving to `keyset-cursor.ts`: no documented standard requires keyset
  here, that helper describes itself as shared by two specific reads, and 15 other `.offset(` calls
  live under `src/server/queries`.
- Kept two named `it` blocks over an `it.each`, and kept the repeat/skip assertions even though the
  order assertion subsumes them, because AC2 asks for them in as many words.
- **`delegate.sh` was used:** one slice, one round, exit 0 (`.ralph/logs/brief-2525-tiebreaker.md`).
  The two review fixes and both commits were the orchestrator's.
