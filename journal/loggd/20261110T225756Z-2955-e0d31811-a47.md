so it was offered on the surface count alone: it mentions the web only as prior art for the

a minimal implementation at 2–6 files, all server-side — a new
`src/app/api/v1/books/[id]/route.ts`, its co-located `route.test.ts`, and a response type in
`packages/shared/src/` plus its export-map entry (the shape of
`packages/shared/src/title-detail.ts`, exported at `packages/shared/package.json:55`). No
`mobile/` file, no page, no schema change. Both v1 conformance tests walk the directory tree
(`route-conformance.test.ts:120`, `profile-subject-conformance.test.ts:211`), so criterion 8

The docstring above `splitThresholds` sanctions exactly this: "the triager's `TRIAGER_SPLIT`

spent — one marker — and the dry-run below confirms the marker is what stops the re-offer.

Splitting it anyway would have produced children needing the parent's text ("the route, but
only its error codes" is not a ticket), which the split rule forbids outright. It is also
already a child of **today's** #2940 split, which took four of that spec's eleven criteria
