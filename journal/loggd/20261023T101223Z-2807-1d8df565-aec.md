# 2026-10-23 — #2807 The PGlite replay exclusions judge SQL, not comments

**Outcome: merged.** PR #2848, merged 2026-10-23T10:10:27Z as `8687c200c`, issue closed

**What it does.** The four PGlite replay exclusion predicates in `src/test/database.ts`
matched raw statement text, comments included, so a migration whose header comment
*explained* the authorization-boundary rule in that rule's own words matched its own
explanation and was dropped from the replay, silently. `stripSqlComments` — a quote- and
dollar-quote-aware scanner, not a regex — now strips comments before all four rules
match; `pgliteReplayExclusion` names the rule that dropped a migration; and
`readReplayableMigrations` reports the drops once per run, keyed by journal tag. Fixture
migrations under `src/test/fixtures/replay-migrations/` plus
`src/test/pglite-replay-exclusions.integration.test.ts` prove AC1 end to end.

**Key decisions.**
- All four rules strip, not only the one the ticket names. Probed first: over all 77
  migrations the stripping flips no verdict under any rule, so the widening was free. The
  change to `isMediaMetadataColumnMigration` is a false-negative fix — it uses
  `trimStart().startsWith`, so a leading comment used to hide a real `ALTER`.
- No fixture under `drizzle/`: a real migration there would have parked a test-harness
  fix on a human applying SQL to production. Nothing outside `src/test/` is touched, so
  there is no migration and no ledger involvement, and the replay set is unchanged (23 of
  77 excluded, same as `main`).
- The excluded fixture's observable DML sits ahead of its policy, so a broken exclusion
  shows up as a renamed row rather than as PGlite erroring on a missing `auth` schema.
- The report is unconditional; `LOGGD_PGLITE_REPLAY_REPORTED` is the single opt-out.
  Documented limitation: a comment inside a dollar-quoted body is left alone, because
  there it is body text.
- Review finding that mattered: "once per process" was wrong under vitest's file
  isolation and would have printed ~130 lines a run. The guard moved into the
  environment; measured once across a five-file run, and still once with no globalSetup.
