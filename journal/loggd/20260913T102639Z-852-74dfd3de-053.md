## What shipped (all under `mobile/`)

- `lib/media-scope.ts`: `isTitleScope`, `mediaScopeFields` (the one optional
  season/episode spread every scoped request now uses — quick actions, list
  membership PUT, the picker's `media`), `resolveScopeWatchTarget` (mirrors
  the web's `useWatchedState`: episode → watched; season → watched if the
  show is ended or the season is complete, else caught_up), `isSeasonComplete`
  (the web season page's rule: an undated episode is unreleased).
- `hooks/useMediaActions.ts`: `useSetSeasonOrEpisodeWatched` — season via
  `POST /shows/:id/seasons/:n/watch-status` `{ action }`, episode via
  `POST /episodes`, throws at title scope; `episodeCascade: true`. Season
  `watched` is **derived from progress** (`released > 0 && watched >= released`)
  in both optimistic and reconcile paths, the way `getScopedActionState` does
  server-side.
- `MediaActionRow`: `seasonComplete` prop; branches on `isTitleScope` for
  the watched action; disables (not "busy") the action for a season with
  zero released episodes. `MediaActionSheet`: Watchlist and Follow render only
  at title scope; sheet titled with `mediaScopeLabel`; picker `media` carries
  the scope. `PickerMedia` gains `seasonNumber`/`episodeNumber`;
  `listSurfaceKeys.compatibleScope` is now a 6-tuple with nulls.
- Season and episode screens swap `LogButton` for `MediaActionRow`; the
  season screen's `getSeasonStatus` badge now uses `isSeasonComplete` so the
  badge and the row can never disagree.
- 133 Jest tests across 7 suites (16 new cases in the hook suite alone).
