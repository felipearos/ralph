## CI trap (read this before touching List query keys)

- **Build #1426 failed in quality**, after about 3 minutes. The cause was two List write hook tests, `hooks/__tests__/useManageList.test.tsx` and `useListMembership.test.tsx`. They seeded the old 3-length `["show", 1396, "lists"]` and expected `mediaListsPredicate` to invalidate it.
- Targeted jest never runs them. **Only the full mobile suite** (`bun run --cwd mobile test --maxWorkers=2`, run once the host was idle) found them.
- They now seed `mediaListsQueryKey(...)` and include a season key. A mutation check went red.
- **Lesson:** any change to a List query key shape needs the full mobile suite, or at least a grep for literal keys across `mobile/hooks/__tests__`.
- `mediaListsPredicate` stays `length === 6` on purpose. Both fix-diff reviewers showed that a looser `>= 3` was untested. With `=== 6`, the `media-lists.test.ts` "every key matches the predicate" test catches any change to the key shape.
