## Key decisions

- **The Acting Member is always member 0**, taken from the credential. `members` names 1–4 others, and each must be followed and not blocked by the Acting Member. The web URL accepts any username, but the acceptance criteria say candidates come from follows, so the API enforces it.
- **Blocks are one-directional** (members the viewer blocked), matching the web profile gate and `/users/network` (`network.ts` filters `blocker_id = viewer` only). The spec reviewer flagged the missing other direction; I kept parity with the web.
- **Summary counts are database counts** (web header semantics). The mobile active tab shows the loaded page's exact post-gate, post-filter `total`.
- **Compare movies do carry `originCountry`** (from `production_countries`), unlike `getWatchlistView`, where movies get `[]`. So movie-only tabs hide only Service, and clear a set Service filter.
