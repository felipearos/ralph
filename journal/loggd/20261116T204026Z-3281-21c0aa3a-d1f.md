## The calls past the mapper's literal overlap map

The mapper offered one 14-ticket server group A (every import ticket) with suggested
cuts it admitted were not file-disjoint. I cut it four ways using **blocker edges to
decide which collisions are live** — the device #3063 and #3083 arrived at:

1. **`jobs.ts` spans two groups on purpose.** #3282/#3284/#3287 hold it in
   `book-import-jobs`; #3288 and #3323 also edit it but are downstream of all three,
   so those pairs are never live. Splitting bought the whole first wave its
   parallelism back.
2. **#3286 keeps its own group although four later tickets reshape the file it
   creates.** #3290, #3325, #3326 and #3328 all edit `book-import-merge.ts` — and
   #3286 blocks every one of them.
3. **`book-import-server` is seven, deliberately.** #3323 is the tie that holds it
   together: it shares `jobs.ts` with #3288, the notification/link records with
   #3289, `packages/shared/src/imports.ts` with #3290 and #3325, and
   `book-import-run.ts` with #3325 — and all five unblock the instant #3287 lands,
   so every one of those is live. Same call as #3028's nine-ticket server group.
4. **#3297 went to `books-profile-mobile` (spec #3063's group), not into this tree.**
   Its edit is the Books-mode profile overview tab #3253 adds, which that group owns.
   This is the first time this loop has put a child of one spec into another spec's
   group; the group name is the collision key, not a tree label, so it is the right
   unit. Worth repeating where a tree's child lands on another tree's screen.
5. **`mobile/__tests__/onboarding-flow.test.tsx` (2,337 lines) was left as a
   cross-group file**, touched by #3294/#3327 and #3333/#3334/#3335 across two
   groups. I checked it before deciding: its `SeenTarget` map is
   `Partial<Record<…>>`, so #3334's widening reds nothing, and the tickets append
   `describe` blocks. Append-only fence rather than a merge — same resolution as
   #3083's `src/lib/hardcover.ts`, and the opposite of #3083's notification lane,
   where the records were exhaustive and tickets redded each other's tests.
