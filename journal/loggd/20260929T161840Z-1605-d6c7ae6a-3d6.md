# 2026-09-29 — #1605 Stop shipping zod on every page via the @loggd/shared barrel

**Outcome: merged.** PR #1836, merged through the Mergify queue at
2026-09-29T16:17:13Z, issue #1605 auto-closed. Parent spec #1586.

**What the change does.** `@loggd/shared`'s root barrel does
`export * from "./schemas"`, and `schemas.ts` builds ~95 `z.object(...)` at
module scope. Those side effects survive tree-shaking, so a single runtime
import from the package root anchored all of zod into the importing chunk —
and via the root layout's client module graph, onto 211 of 398 routes. Fix:
`"sideEffects": false` plus `./movie-releases` and `./network-types` subpath
exports on the package, the nine `src/` modules that pulled a runtime value
from the root repointed at subpaths, and an ESLint guard (scoped to `src/**`)
so it cannot regress.

**Measured result** (per-route client JS, gzip -9, both builds from merge base
`17fa9f47b`): `/` 579.2 → 515.4 KB, `/show/[id]` 618.4 → 554.6 KB,
`/movie/[id]` 606.1 → 542.3 KB, `/[username]/network` 607.2 → 543.4 KB; raw
fell by exactly 273.3 KB on every route. Scanning all 398 client-reference
manifests: **211 of 398 routes carried zod before, 5 after**. The five that
remain validate on the client and reach zod through a subpath that owns it.

**Key decisions.**

- **The guard had a real hole**, flagged by both review axes and confirmed by
  probe rather than by reasoning: `@typescript-eslint/no-restricted-imports`
  inspects only static import declarations, so `await import("@loggd/shared")`
  and `require("@loggd/shared")` passed clean. Closed with `no-restricted-syntax`
  selectors and covered by tests. Worth remembering as a general fact about
  that rule.
- **A custom local ESLint rule was ruled out** — the stock rule honours
  `allowTypeImports` and catches `export … from`, and #1586's testing decisions
  name `no-restricted-imports` explicitly.
- **Mobile deliberately untouched**, guard stops at `src/`: out of scope per
  #1586, and ~50 mobile modules import values from the root.
- **Two corrections to the audit's description** went in the PR body: the zod
  chunk was never a `rootMainFile` (it was a shared chunk reached through the
  root layout's module graph), and "every page" was 211 of 398 routes.
- **`delegate.sh` was used**, two slices, one round each: the nine import
  rewrites and the regression test. The orchestrator wrote the
  `packages/shared/package.json` and `eslint.config.mjs` edits directly (three
  lines and one config block), reviewed both diffs, and did all review fixes.

**Files touched.** `packages/shared/package.json`, `eslint.config.mjs`,
`eslint-rules/no-shared-barrel-value-imports.test.ts` (new), and nine `src/`
modules including `src/lib/tmdb-client.ts` and `src/server/imports/types.ts`.
