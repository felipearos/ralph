## Key decisions

- **One-directional block filter kept.** `members-directory` omits both sides of a block; this read omits only members the viewer blocked. Making it mutual would change the shipped web page, and the issue says to preserve "blocking hides content but does not rewrite the follow graph". Declined deliberately; **worth its own ticket.**
- **Sort stays component state**, not the URL. Web keeps `?sort=`, so a mobile sort is not deep-linkable. Not asked for.
- **`parseIntParam` bug found, not fixed:** `parseInt(...) || defaultVal` treats a parsed `0` as absent, so `limit=0` falls back to 20 rather than clamping to 1. Pre-existing and shared by ~30 v1 routes, so out of scope; the test asserts the real behaviour. **A genuine follow-up.**
