## What shipped

Paired migrations declare the previously hand-made `profile-backdrops` bucket
(public read, 5 MB limit, four image MIME types) and four `storage.objects`
policies scoped to `(storage.foldername(name))[1] = auth.uid()`. The E2E
fixtures stop creating the bucket and now throw if a reset is missing.
`updateProfileBackdropCore`, `removeProfileBackdropCore` and the cover-override
core resolve the storage object through `ownBackdropObjectName(userId, url)`
instead of trusting the stored URL, which closes a cross-member delete. The
deployed-state verifier gained bucket and storage-policy drift reporting, and a
storage suite joined the authorization harness.
