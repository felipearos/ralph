**Key decisions.**
- **Hide set, not keep list.** A keep list over `MEDIA_TYPES_BY_MODE` would hide the seven media types belonging to no Media Mode from everyone, breaking AC7. The lib test derives those seven from the schema enum rather than hardcoding them.
- **The predicate is shared, not copied**, so phone and web cannot drift and AC6's mutation has one place to bite.
- **The grant read is conditional**, which is why no existing caller pays a query and why `notify.test.ts`'s FIFO select queue is unshifted. Two sentinel tests pin that.
