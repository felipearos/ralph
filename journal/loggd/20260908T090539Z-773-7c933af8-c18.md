`publishedReviewPredicate()` (draft/hidden → Outcome Reason `not_found`,
same as the comment core and what keeps the visibility ratchet baseline from
growing), then insert-or-delete plus `count(*)` in one transaction, answering
`{ isLiked, likesCount }`. `isReviewLikedBy` is exported beside it for the
endpoint's old-client toggle. The v1 route honours body `{ liked }`, treats
an EMPTY body as the pre-flag phone (read state through the module, set the
inverse), and a present-but-unparseable body as 400 `VALIDATION_ERROR` —
`readJsonBody` cannot tell those apart (both come back `null`), so the
route reads `request.text()` itself. `RAW_WRITE_ROUTES` is now
`notifications/route.ts` alone. Phone hook takes `{ liked }`; both hooks

`reviewLike-write.integration.test.ts` drives web action + v1 route on
