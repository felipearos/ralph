## Read this first if you are taking another #760 core

**The review-visibility ratchet will fire on you, and the right answer is
not to grow the baseline.** The old action never checked the review existed;
the old route let the FK violation become a 500. A bare
`select … from review where id = ?` existence check is a second unguarded
scan in the new declaration, and "the baseline never grows" refused it. The
executor's answer was to bump the count to 2 and write a MOVED_SCANS entry;
the actual answer was `and(eq(review.id, …), publishedReviewPredicate())`.
That is not a workaround: a member may comment on exactly the rows a reader
is shown, a draft or moderator-hidden review is answered as *missing*, and the
web page already filters with the same predicate so no composer ever renders
where the gate would bite. The declaration then mentions the predicate, every
scan in it counts as guarded, and the entry is deleted rather than moved.
Spec review judged it within intent, not creep. Expect the same shape on
#771 (review delete) and #773 (like).

**Three conformance suites move with a core, not one.** Extracting a write
out of an action touches `route-conformance` (the raw-write line),
`review-visibility-conformance` (the scan's key) and
`notification-creation-conformance` (the `notifyAfterResponse` site). Grep
all three before the first `bun run test`, and put them in the brief's gate.

**The action's result type is deliberately not the core's.** The transport
also returns the member refusal, so re-exporting the core type (as the List
comment action does) fails typecheck; the delete core already has the same
two-declaration split. The standards reviewer flagged the duplicate name; the
repo convention wins, and a comment now says why.

## Two things to know about this host, today

- **Vitest filters:** a bracketed path like `reviews/[id]/comments/route.test.ts`
  breaks the whole filter list ("No test files found"), and so does passing
  the list as one zsh variable. Use `grep -rl … | xargs bun run test`, and pass
  bracketed files as a parent directory.

  journal-only) and #1241 (my rebase) started in the same second on two
  agents and both died with exit 1 within one second, 7 minutes in. Same shape
