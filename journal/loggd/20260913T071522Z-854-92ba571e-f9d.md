## What shipped (in the PR)

**Server** — `GET /api/v1/users/stats` gains two sections under #847's single access rule:
- **`section=years&scope=tv|movie`**: the member's real activity years.
- **`section=hero&scope=tv|movie[&year]`**: scope-discriminated totals.
  - TV: shows, episodes, hours, averageRating, reviews, countries.
  - Movie: movies, directors, movieDays, longestWeeklyStreak, plus the shared fields.
  - The query answers 0 for metrics it skips, so each scope returns only what it computes. That is the AC's "without inventing unavailable values".
- **Validation happens before the member lookup**, inside the section switch; each case builds its loader.
- **`parseStatsYear` / `rangeForStatsYear`** moved from the web stats page into `src/lib/stats-year.ts`. They are shared by the page and the route; the web page's behaviour is unchanged.

**Mobile**:
- **`useUserStatsYears` / `useUserStatsHero`**: `StatsNotFoundError` joins `StatsForbiddenError`, and neither is retried. The summary hook uses the same `throwOnStatsError` / `statsQueryRetry` helpers.
- **`mobile/lib/stats-hero.ts`** holds the payload types, `MediaScope`, the `formatHeroCards` formatter and `isHeroEmpty`.
- **Zero vs unavailable**: a 0 renders as `0`. A null average rating renders as a dimmed `—` with a "not available" a11y label.
- **Screen `profile/[username]/stats.tsx`**:
  - Scope and year live in route params. Defaults are the viewer's Media Mode and All time.
  - Changing scope clears the year. A route year outside the loaded years falls back to All time.
  - Year chips and hero load independently.
  - The "Member not found" check comes **before** the profile gate's error. `/users/profile` 404s too, and `apiQueryFn` drops the code.
- **Another member's profile** gets a See all stats row. Insights values stay own-profile only.
- **Maestro** `profile-stats.yml`: Insights → hero → Movies. Not run (device constraint). It needs an account with TV and movie activity.

**Glossary**: added **Media Scope** to CONTEXT.md. It is distinct from Media Mode; _Avoid_: Stats Mode, Stats Tab, Media Type.
