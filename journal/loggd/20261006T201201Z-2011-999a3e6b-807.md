**Key decisions.**

- The frame reads `voteAverage`, `voteCount` and `stats` off `frame`; only
  `posterPath` and `popularity` are passed beside it, being the two provider
  fields `TitleFrame` carries no field for. The first brief duplicated all three
  as props; caught in diff review.
- `MovieContent` keeps its local-time `year` rather than `frame.year`:
  `getUTCFullYear` vs `getFullYear` differ by one on a year-boundary release
  date, and that is a visible change this refactor must not make. `frame.year`
  is therefore unused by the movie screen; **#2015 reconciles it.**
- The doubled backdrop pull-up is preserved verbatim — `MovieContent` wrapped
  each `Backdrop` in a div duplicating `Backdrop`'s own container offsets
  (`Backdrop.tsx:18-19`), where `ShowContent` applies them once. "Movie screen
  unchanged" is a hard AC, so the frame copies the movie markup. **#2013 must
  settle which screen is right**; it is called out in the PR body.
- Tab bar is `<Tabs showBorder />` (Tabs' own solid `border-b border-purple-500`),
  the token the movie screen already drew. The show's `border-white/10`
  (`ShowContent.tsx:607`) converges in #2013.
- Extra tabs go around the shared Cast/Crew/Details triple via
  `leadingTabs`/`trailingTabs`, which keeps movie's Cast, Crew, Details, Releases.
- `shouldShowOriginalName(frame.displayName, frame.originalName,
  frame.originalLanguage)` is equivalent to the old call on raw provider fields:
  `originalNameOf` (`title-frame.ts:49`) is a strictly weaker pre-filter.
- One AC item was read as not applicable and flagged in the PR body for the
  owner: the story has no skeleton, because no frame skeleton exists and this
  slice introduces none. The movie skeleton stays the route's `loading.tsx`,
  which is now a third copy of the shared layout — #2015's problem.
