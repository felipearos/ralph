  strips. Disjoint from the step list, the snapshot and the grid.

#2479 removes the global "Skip setup" action from the media step, which lives in the flow /
step-layout rather than in the media cards, so the cards are #2489's alone. The payoff is that the
three tickets unblocked **today** — #2479, #2486, #2489 — each sit in a different group and can run
in parallel. The #2487/#2488 ↔ core edge I did **not** break: it is a shared `profiles` boolean plus
a migration number, and that is the expensive kind of collision.

Nothing else was written: no labels, no acceptance criteria, no blockers, no closures. #2479 is held
by `rafa-wip`, so only its `## Staffing group` was set — the one section the tool allows on another
loop's issue. This was a label-only (staffing) unit, so `review.spec` was correctly skipped; there
was no spec text to review.
