## What shipped

Two v1 write routes — `POST /api/v1/books/<id>/rating` (`{ score: number | null }`)
and `POST /api/v1/books/<id>/like` (`{ liked: boolean }`) — as Thin Transports over
the existing `quickRateExternalCore` / `quickLikeExternalCore`. Both are
desired-state, so a replay lands on the same state and a double-sent like never
undoes itself. On the app, `useSetBookRating` and `useSetBookLiked` joined the Book
Library Write module and the Book screen's action bar gained the shared `RatingRow`
plus a like heart. 8 files of production code and tests plus `CONTEXT.md`, 7 commits
`45e5e2443..c0bb6cdce`.

## Key decisions

- The like body is desired state, unlike the web action's toggle; that needed a new
  shared `setBookLikeSchema`. The rating reuses `quickRateBookSchema`'s `score`, so
  one 0–5 half-star scale serves shows, movies and books.
- Layout: the three status buttons keep their row and the rating band goes below it.
  Ruled out a fourth equal button (four labels crowd a phone) and ruled out editing
  `RatingRow`/`RoundAction`, which the media sheet shares.
- A rating and a like written from the app stay invisible without the Media Mode
  preview, pinned by a test.
