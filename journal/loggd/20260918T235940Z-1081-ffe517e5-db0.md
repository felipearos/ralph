## What I changed after reading the diff

1. **Removed the focus gate on the suggestion row.** Touching a chip blurs the `TextInput` first, so a focus-gated row unmounts under the finger and the press never lands — the standard React Native autocomplete trap. The executor had implemented it exactly as my brief asked; the brief was wrong.
2. **`myTags?.items?.map(...)`** — the executor's `myTags?.items.map(...)` threw on any answer that is not the tag page, taking the whole log flow down. Caught by running the *neighbouring* `log-movie-flow.test.tsx`, whose generic `api.get` mock returns `{shows: []}`. This is the "a new provider call on a screen breaks every test file that mocks that screen" lesson again — it is worth grepping `__tests__` before pushing, not after.
3. **One `normalizeTagName`** governing add, match and create (standards finding): the filter matched case-insensitively but excluded selected tags case-sensitively.
4. **`ExistingLog.tags` made required** (spec finding): `log-write.ts` deletes a log's `reviewTag` rows before re-inserting the payload's, so an `openLog` that forgot to carry them would strip tags silently. A type error is better than data loss.
