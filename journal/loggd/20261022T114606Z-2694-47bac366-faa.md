## What landed on the branch

A shared guard `src/server/movie-page/require-visible-movie.ts` (`movieVisibleToViewer`
answers, `requireVisibleMovie` 404s), wired into nine movie surfaces in both the
body and `generateMetadata`: the seven `(subpages)` pages, `/stats`, and the

## Key decisions

- **The spec, not the gate, was the weakest part of the change** — both review
  axes said so independently. The E2E spec had flipped `media_metadata.adult`
  on tmdb **238 (The Godfather)**, a real movie, restoring what it read: a
  worker killed between the flag and the `finally` left 238 flagged forever,
  since the next run read `previous = {adult:true}` and "restored" it, and
  global setup never resets `media_metadata`. It now owns dedicated id
  **990002075**, so cleanup is an unconditional delete.
- **The control had to be the same movie.** It rendered The Matrix (603) while
  asserting absence on 238 — a cast page 404ing for any unrelated reason passed
  every absence assertion *with the gate deleted*. It now seeds 990002075
  unflagged, asserts title and poster render, then flags and re-asserts.
- **A stale stored flag is trusted, deliberately.** Both axes raised that the
  guard never re-asks TMDB while `gateAdultMedia` reads live, so a stale stored
  `adult=false` reopens SEC-06 for that movie. AC1 prescribes stored-first, so
  the spec won over the reviewer: it is written into the guard's docstring and
  flagged in the PR body as follow-up work for a human to rule on. **No
  follow-up issue was filed** — that call belongs with the operator.
- Two documented deviations from AC1's literal wording: `generateMetadata`
  calls the non-throwing `movieVisibleToViewer`, and the `(subpages)` layout
  gates its header but never 404s (the conformance test is what makes relying
  on the children safe).
- TMDB fixtures could not be copied: `e2e/tmdb-fixtures.ts` stores each
  request's identity inside the fixture, so a hand-edited one is a miss. Both
  new recordings were verified against `tmdbFixtureFileName(request)` directly
  rather than on the executor's word.
