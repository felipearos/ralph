**Key decisions.**

- *Why the diff is bigger than the issue's Evidence section implies.* Each
  screen's full-screen error branch had to be narrowed to `isError &&
  <items>.length === 0`. Verified in the installed
  `@tanstack/query-core` 5.90.20: `queryObserver.js:309` sets `isError` whenever
  status is `"error"`, regardless of whether `data` exists. Without the
  narrowing, a failed *next* page replaces the loaded rows with the full-screen
  error and takes the footer with it, making AC1's inline error unreachable.
  `network.tsx:156` already used exactly this form, so this is conformance to
  the reference screen, not new design. Both review axes examined it and judged
  it in scope.
- *Declined, for a follow-up.* Consolidating the ~14 copies of the guard and
  the two identical `NextPageFooter` helpers into one shared footer plus a
  `usePagedEndReached(query)` hook. Deferred deliberately: the issue states the
  profile paged collection screen spec removes the copied wiring structurally,
  so a shared abstraction now would be rewritten by that ticket.
- *A real gap found by review and deliberately not fixed.* With rows already
  loaded, a failed pull-to-refresh shows no error at all —
  `isFetchNextPageError` is false for a refresh. This is `network.tsx`'s
  pre-existing behaviour, so the change makes every screen consistent with the
  reference, but refresh feedback is missing across all 12. It belongs to the
  paged-collection spec, not here.
- *AC4 is met as written* (one screen per wiring), which means it is weak:
  removing the guard from Movies, Reviews, Activity, three of the five Likes
  bodies or a tag body fails no test. Noted rather than over-tested.
- *No `CONTEXT.md` change.* The glossary carries no entry for the paged-list
  end-reached rule, "refetch while viewed" or "Invalidated Root". These are
  behaviour rules rather than domain concepts and the issue's own wording was
  used consistently throughout; if the paged-collection spec names the concept,
  that is the ticket that should add the entry.
