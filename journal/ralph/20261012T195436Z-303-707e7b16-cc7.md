## What shipped

`host-lease.ts turn-begin` is the supervisor's wait before every model turn.
Held because a sibling loop holds the host lease, it used to sleep in 15 s
slices and consult nothing else for up to ~2.5 h (a drain plus a grant), so an
operator's Stop or pause went unread for that whole time. It now checks
`hasPendingCommand` on `RALPH_PROJECT` after each slice and, on a pending
command, prints `HELD_CONTROL_LINE` and returns 3 without registering a turn.
`orchestrator_turn` in `ralph.sh` loops on exit 3: `control_checkpoint`, then
end the run on a stop as the iteration checkpoint does, else ask again. Any
other status lets the turn through unchanged. The two halves cannot be split —
exit 3 alone would let a held turn start unregistered.

## Key decisions

- **The plan's test code could not work as written.** Plan 005 Step 2 builds
  the holder store with the fixture clock `T0` (2026-09-29), but `main` prunes
  against the real `Date.now()`, so the holder was lapsed before `heldBack` was
  consulted and the test returned 0 instead of 3. The holder is now built with
  `Date.now()`, with a comment saying why, and the store file is the fallback
  `<root>/.ralph-host-lease.json` rather than `storePath()`'s own file.
- **The new `ralph.test.ts` tests need `REAL_CONTROLS: '1'`** — the default
  fake `controls.ts` answers polls from knobs and would never see a stop
  written into the worktree's inbox.
- **Two P2 findings left in deliberately**, each a comment at the decision and
  both flagged in the PR body and the merge comment for the operator: (1) a
  stop consumed at a held turn exits without closing the iteration, so a hold
  on a second or later turn can leave `iteration-start` without
  `iteration-end` — the fix touches all seven `orchestrator_turn` call sites
  and deserves its own ticket; (2) `control_checkpoint` is called at the hold
  with no boundary, so a pause meant for a phase is consumed there and a
  follow-up `retry-phase` would be refused.
- **No rebase.** `origin/main` moved (notably #309 for #301, in `dashboard/`)
  with no textual overlap. Open learning `ralph-repo-no-merge-queue` applies:
