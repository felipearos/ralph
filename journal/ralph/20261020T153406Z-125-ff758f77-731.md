- The readiness fold runs on the existing five-second `GET /api/agents` poll.
  Criterion 3 names that route and fences off only preflight, and nothing runs

  body names it and proposes a short-TTL cache as its own ticket rather than a
  quiet redesign here.
- The guide's example values are parsed out of the guide's own opening note,
  because `plugin-boundary.test.ts` forbids the core naming the operator's
  workspace manager, and a hardcoded example worktree path is that name.

  against `roleDescriptor(role).javRouted` in `adapter.test.ts`.
- The serious local finding, found by review and fixed before the PR:
  `parsePreflightJson` read a flat `check.state` where `preflight.ts` prints
  `{ name, outcome: { status } }`, and the test fake had copied the same
  invented shape. Now pinned against the real CLI.
