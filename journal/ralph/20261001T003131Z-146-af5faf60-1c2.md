**Key decisions.**
- `shepherds` is derived from the sigil set rather than added as a descriptor field: the sigil
  IS the question, and a parallel field could only drift from it.
- The gate names a read-only role's violation but neither spawns nor repairs it. Spawning would
  wake an iteration whose prompt may not edit a file, which returns blocked and walks into
  `BLOCKED_STREAK_LIMIT` — the rafa halt. `role_invariant` repairs it at an iteration's end.
- The poll default lives in `start.sh`, not `ralph.sh`: an empty `RALPH_WAIT_FOR_WORK` in
  `ralph.sh` means ungated, so a default there would silently turn a one-shot run into a
  waiting one.
- Review caught two real defects, fixed in `fdd9f56`: `baseRef()` read `RALPH_BASE_REF`, which
  `ralph.sh:183` assigns *without* `export` — a dead clause hiding a hardcoded `main`; and the
  violation note was dropped on five verdicts, three of them the undetermined waits that
  repeat for hours.
- Stated gap, flagged in the PR body: AC 3 is met in two halves (apply-layer ledger
  idempotency, plus the gate giving a definite empty answer so no second iteration spawns),
  not by a single end-to-end test.
