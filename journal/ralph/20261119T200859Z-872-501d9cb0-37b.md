CLI; the dashboard reads it and relays three commands (eval-inbox-add, -start,

screen in the Evals tab and Add to inbox on the Run screen; README section.

## Key decisions

- start/dismiss carry the entry id under body key `entry` (the relay stamps `id`).
- Inbox rows are summaries, never plans.
- start claims the entry under the store lock first and restores it if the start is refused.
- add is validated by `checkStart`, extracted from `startRun`, so an add is checked as a start would be.
