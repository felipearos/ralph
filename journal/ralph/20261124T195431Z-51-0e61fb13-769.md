## What changed

the PR's state; `direct` is never queued. Prompt step 6 renders route/enqueue/requeue per method (models.ts
`mergeRoute`/`mergeEnqueue`/`mergeRequeue`); ship-prompt next step per method. Absent = byte-identical render, same gh calls.
README documents it; dashboard classifies mergeMethod as edited in the config file.
