# 2026-10-06 — #233 Exempt urgent/ci-health filings from Jav difficulty routing

**Outcome: merged.** PR #236, squash-merged as `7eab3f1`, issue auto-closed.

**What it does.** With Jav difficulty routing on, `routeByDifficulty` filtered
out every ci-doctor filing — those carry no difficulty label and cannot — so a
red base branch was offered to no coder at all. `jav.ts` now exempts a
`priority:urgent` or `ci-health` ticket that carries none of the project's
configured difficulty labels, and nothing wider. `untriagedTickets` drops the
same tickets from the triager's routing bucket, and every label a filing can
carry (`bug` included) is reserved, so a project cannot configure routing on one
of them and silently switch the exemption off.

**Key decisions.** Shape 2 of the three #233 sketched, keyed on labels, widened
by `ci-health` for AC 4 and then narrowed to only the tickets routing would
STRAND. The narrowing came from the #153 pin — "is still filtered out by a route
that does not take it" — which is right: a *triaged* urgent ticket must not be
handed to a loop routed away from it.

Ruled out: a discriminated union on `roleUnits`' options in place of the runtime
throw (it reshapes a type every role's caller passes, for a condition no
production call site can reach — the throw covers it); and a seam to count
`jav.json` reads in `main` (the comment now says the memo is not pinned rather
than implying it is).

**The one wart, declared in the PR body.** `origin/main` was already red before

against loggd's `origin/main`, and felipearos/loggd#2130 had merged there. The
pre-push hook runs the whole suite, so no push to this repository was possible
until the fixture caught up. Two commits in this PR are therefore not this
ticket: the `bun sync-fixtures.ts` refresh, and the `prompt-render.test.ts`
helper that lets the loggd fixture carry a ci-doctor. They are separable and the
PR body says so; nobody could have pushed anything without them.
