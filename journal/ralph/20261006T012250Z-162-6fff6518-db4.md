## Key decisions

1. **No store schema change and no `CI_HEALTH_VERSION` bump** — only an
   optional `Revert.rounds?`. A version bump discards a live 72-hour window on
   deploy, which is too high a price for an additive optional field.
2. Revert branches are `$RALPH_LOOP_NAME/<issue>-revert-<sha>`. #162's example
   wrote `doc/`, which is what that renders for a doctor loop named `doc`.
3. **`ci-doctor/gh.ts` is the lift `unpark.ts:198-201` explicitly asked the
   third caller to make.** `tried()` was added for degrading reads.
4. `retire` takes no case key: the gate stops offering a regression the moment
   it retires, so a single-key form could never be called.
5. Review round 2 caught a HIGH defect that round 1's own fix had introduced —
   the resume shortcut keyed on a store field written only after `gh pr create`,
   so a crash in between would re-open the PR. It is now keyed on `ls-remote`.
   Two review rounds earned their keep here.
