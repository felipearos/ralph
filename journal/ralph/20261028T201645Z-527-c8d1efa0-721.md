## What changed
- `tracker/local.ts`: new kind `local`. It is the keyed in-memory fake, persisted to one JSON file. Writes take a lock file with a token (stale after 10s, wait up to 20s) and use fsync+rename. `seedLocalTracker` seeds a trial's frozen ticket.
- `project-config.ts`: `tracker.kind: "local"` takes `{key, file (absolute), states?}`, with no scopeLabel. `createTracker` builds it before it reads any credential, with self = config.owner.
- Dashboard: `TRACKER_KINDS` in `onboarding-model.ts` never offers `local`. The connect routes refuse it, and the adapter and chat handback treat `local` as keyed.
