**Key decisions.**

- **The §7 release-marker format deviates from the issue deliberately.** Spelled as the issue
  writes it (`<!-- ralph-triage v1 loop=… -->`) it would not parse in `triage-marker.ts`, so
  `hasCurrentTriage` would never see the decision and every triaged issue would sit in the intake
  bucket forever. The fields ride as extra keys on the format that module already reads
  (`parseFields` ignores unknown keys), percent-encoded so a label like `good first issue` cannot
  break it. Both review axes judged the deviation defensible.

  name with no implementation behind it is configuration that looks live.

  is ever offerable: a half-applied split is a backlog nobody can reason about.

  is not driven in a test, because it materialises its payload from the harness's `origin/main` and
