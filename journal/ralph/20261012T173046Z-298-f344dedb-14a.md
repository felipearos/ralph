## What changed

Ralph runs its own loops against this repo, but `.ralph/prompt.md` was still
the generic template: it pointed at a `CLAUDE.md` that did not exist and
prescribed `npm test` / `npm run typecheck` / `npm run build` on a Bun-only
repo with no npm scripts and no `build` script at all. `.ralph/coder.md` had
the same npm gates. An iteration following them would fail its own §4 gate on
environment rather than on the diff.

The change adds `CLAUDE.md` (a 70-line entry doc: commands, where things
live, rules for changes), replaces both `.ralph` fragments so they point at it
and name the real bun gates, and adds `ralph-fragments.test.ts` (2 tests)
pinning that the fragments name no npm script and do name the bun ones.
