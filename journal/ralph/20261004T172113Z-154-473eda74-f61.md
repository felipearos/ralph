# 2026-10-04 — #154 CI doctor: bk-log.ts prints a `known:` line for known failures

**Outcome: merged.** PR #220, squash-merged as `494663b`, issue #154 auto-closed.

**What shipped.** `bk-log.ts` now reads the ci-doctor's store
(`<git-common-dir>/ralph/ci-health.json`) with no API call and prints, under each
failing test the store knows, the doctor's verdict: a confirmed flake with its
red count and open fix PR, a main-red regression naming the build the test went
red on, or a branch-only failure that is likely the diff. Plus a `known infra:`
section for open incidents, and the same data in `--json` under a `known` key.
A missing, corrupt or silent store leaves the text digest and the exit code
byte-identical — that invariant is what made the change safe to land.

**Key decisions.**
- `identify` moved to `ci-doctor/store.ts`, beside the key grammar it builds
  (`90c5fe3`), rather than staying where `known.ts` could reach around it.
- `--json` always carries `known`, even when empty: a consumer should not have to
  distinguish "no store" from "store says nothing".
- The regression line uses the lowest evidence build rather than `store.main.build`
  — the first red is the useful one for a bisect, not the latest.
- A `fixed` flake still prints while a fixed regression does not.
- **Not taken:** raising `LIMITS.failures` (the cap truncates the failure itself;
  the overflow line now counts the known ones instead), and keying "open" off
  `filed`/`fixing` — nothing writes `Case.pr` until #159/#162 land.

**Review earned its keep twice.** Round 1 found that every pre-existing
`bk-log.test.ts` `main()` call was reading the operator's LIVE `ci-health.json`,
because `test-ralph-env.setup.ts` deletes `RALPH_PROJECT` and `readKnown`
resolved its path from `process.cwd()`. It passed only because no doctor has run
on this repo yet. Round 2 then caught round 1's *own* fix: deleting `flakeClaim`'s
`default` arm to make the switch exhaustive removed the only runtime guard for an
absent `state`, so the digest printed the literal line `known: undefined`. Both
axes found it independently. The lesson is narrow and reusable: making a switch
exhaustive over a *declared* union deletes the guard that a malformed
deserialised value needs.
