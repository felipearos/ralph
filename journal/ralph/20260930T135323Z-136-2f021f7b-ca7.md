**Outcome: merged.** PR #203, squash-merged as `0dbf52c` on head `25e98a2`; issue #136 did NOT

**What shipped.** A role (`roles.ts`, `RolePreflight`) declares which startup preflight checks
it is held to, which failing verdicts it overrides, and which extra project labels it cannot
work without. `preflight.ts` reads that: a check the role does not list is not RUN, an override
rewrites a `warn`/`denied` outcome (never an `unavailable`), and `loop-labels` requires the
role's vocabulary plus the project's Jav difficulty labels on top of the per-loop triple.
`preflight.ts --labels` prints the whole set for the Add-agent flow with no probe at all.

**Key decisions.**

- `PREFLIGHT_CHECKS` lives in `roles.ts`, not `preflight.ts`: a role's list must be a typed
  subset of one list and the reverse import would cycle. `CheckResult.name` is typed against it,
  and a test pins a coder's emitted names to equal the vocabulary in order — so a vocabulary
  name nothing produces cannot become dead configuration.
- Because of that fence, **`buildkite-retry` is deliberately not in the vocabulary.** The spec
  axis called the omission "defensible but not complete"; the standards axis's finding that a
  name with no call site is expressible dead config settles it. It becomes one line in
  `roles.ts` when the ci-doctor's ticket implements the check.
- A role states its DROPS, not its asks, so a check added later applies by default.
  `MANDATORY_CHECKS` (`project-config`, `tools`, `loop-identity`) is what no list may drop,
  fenced by a test because `preflight.ts` runs them regardless.
- `requiredTools(config, role)` drops the secrets CLI for a role with `secrets.manager: false`
  — beyond the ACs, but dropping `doppler-scope` alone still left a triager refused for a
  `doppler` binary it never invokes. Both review axes judged it justified.
- AC 4 met by EXPOSURE, not dashboard wiring: `dashboard/agents.ts` creates no labels at all
  today, not even the triple, so making it create them would be new behaviour for every role.
- `javLabels` was renamed `requiresDifficultyLabels` — it sat beside `javRouted` meaning the
  opposite thing for every role.
