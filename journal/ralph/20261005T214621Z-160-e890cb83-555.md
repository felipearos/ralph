**Key decisions.**
- **No new route, no new fetch.** The read rides on `RuntimeSnapshot.ciHealth`, the way `frontier`
  already does.
- **The git common directory is resolved by READING `.git`**, not by `git rev-parse`:
  `read-only.test.ts` pins that `adapter.ts` starts no second process. `commonDirOf` documents why
  it is neither `storePathFromGit` nor `projectIdFor`.
- **A missing store folds to an EMPTY view; `view: null` is reserved for an unresolvable path.**
  That split is what makes AC 4 testable.
- **`RolePanels.ciHealth` is derived from the descriptor** (`preflight.labels.includes("ci-health")`),
  never compared against the name `ci-doctor`.
- **`CiHealthView.held` is a flat list of every leased case**, whatever list draws it — a parked
  ticket is leasable, and a search over the drawn lists reported a doctor mid-unpark as idle.
- **The CI-time figure is an estimate from median red-BUILD wall time.** No per-job duration is
  persisted anywhere; disclosed on its one printing surface and in both READMEs.
- `RETRY_CEILINGS` is now exported from `project-config.ts` so the parity test can fence the
  mirrored default.

**Ruled out.** A job-duration field on `BuildRecord` — a scan change, and the `CI_HEALTH_VERSION`
bump it forces would discard a live 72-hour window on deploy.
