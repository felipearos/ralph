## Key decisions

- A state move that cannot be made is a **warning on a created issue, never a
  throw**: losing the number of an issue that exists is the worse failure.
- Linear's cancelled state is found by **type**, with `states.canceled` as an
  override; a configured name the team lacks still cancels and reports the typo
  on the move. Jira has no cancelled type, so `states.canceled ?? states.done`.
- The contract's new body literals carry **no trailing newline**: an ADF round
  trip drops one, and demanding it would fence Jira out over a difference no
  caller can see. `SEED` was untouched.
- Ruled out: making the fake refuse unknown labels — it would change
  `addLabels`, which AC5 forbids. The interface doc now states what each
  tracker really does instead.
