validated, role-gated key of `.ralph/config.json`. README and two stale comments
updated.

**Key decisions.**

1. **A gate-only secret is invisible to the preflight.** `ralph.sh:1651` unsets it
   in the very shell `:1728` spawns the preflight from, so AC 2 as literally
   specified could never be satisfied. Hence the two name lists — the preflight
   learns which credentials exist without any of them crossing the boundary.
2. **A credential with no checker is withheld, not available.** Both review axes
   found this; the first draft's warning was permanent and its remedy wrong.
3. **Round 2 found round 1's fix had inverted the defect** — reporting `ok` on a
   merely visible token is a false reassurance on the hand-run path. `ok` now
   requires a checker, not just visibility.
4. **The validated key set is wider than the issue's example** (#152's two timeout
   ceilings are in it), stated in the PR as the spec owner's call.
5. AC 1 and AC 3 were already met on `main` by #133/#136 — no new work there.
6. Not taken: retyping `ci-doctor/gate.ts`'s `main` to drop a cast. Real, but a
   separate cleanup.
