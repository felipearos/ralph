## What shipped
A pure guardrail-verdict module for evals two-arm set runs that have a live
baseline arm: it judges both goals (quality, cost) against the noise floor and
gives a reason for every condition. The verdict is stamped into a set run's
report.json/report.md, carried to the dashboard run view, and shown per goal on
the Results tab. The thresholds come from the project config's `evalsGuardrails`,
which refuses unknown keys by dotted path.

## Key decisions
- The baseline is the single live, no-overlay arm of exactly two agent arms.
- Both goals are judged, because runs carry no goal yet.
- The comparison is over paired cases, and a coverage condition requires every case to have run.
- Cost is reported USD only, else tokens.
- delegate.sh wrote slices A (the pure module) and D1 (run view/adapter); B, C and D2 were written directly (small, followed existing patterns).
- correctness: 0 P1, 2 P2, 2 P3 — 3 fixed, 1 dropped (objective-not-down fails with no objective cases; kept conservative).
