## Key decisions

- **Byte identity (AC 4) by rendering only the lists.** The prose stays in
  `prompt.md`. For a four-loop roster the render matches `origin/main` bar the
  `Rulo` the capitalisation example was missing. `prompt-render.test.ts` masks
  the four lists out of both renders and asserts the rest is equal, so the
  fence also catches a reordering — hand-verified that it bites on an unrelated
  prose edit.
- `rosterProvenance` wraps at 79 columns with a 19-column first-line offset,
  reproducing the original's line break. `PROVENANCE_LEAD_IN` is exported and
  checked against `prompt.md`, so rewording the lead-in cannot leave the wrap
  budget silently wrong. Code spans are unbreakable atoms.
- All four renderers **refuse an empty roster**: `""` would render
  `git ls-remote --heads origin` with no pattern, listing every head.
- This narrows #134's "a joining triager changes no coder's prompt" promise on
  purpose; raised in the PR body.
- Section numbers deliberately untouched — `phase.ts` and `ship-prompt.ts` key
  on them.
