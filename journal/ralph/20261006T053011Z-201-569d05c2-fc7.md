**Key decisions.**

1. **The executor and both inspect runners are down, and the cause is known.**
   `delegate.sh` exits 4 with an empty log; `opencode run --model
   opencode-go/deepseek-v4-flash` answers *"An active OpenCode Go subscription
   is required to use Go models."* Both `inspect.sh` routes fail identically
   (exit 1, `runner-error`). So `delegate.sh` was called once and could not run;
   the mapper and both review axes went to route 3 (in-session `Agent` on opus),
   and every slice was written in session. **All six slices were delegable** —
   nothing was carved out as too sensitive to hand over. Published as the
   harness learning `opencode-subscription-lapsed` (see below), because it will
   hit every later iteration until an operator renews the subscription or
   re-points `models.json`.
2. **The review earned its keep.** The standards axis found that a draft body
   containing an unfenced `## ` heading corrupted the shared file: the heading
   became a top-level section, pushing every entry below it out of `## Open` —
   which blinded the duplicate guard, under-counted the dashboard, and
   reparented old entries on close. Reproduced before fixing; closed by a
   write-boundary refusal in `addEntry` plus fence-aware scanning.
3. **The cap had to name what it drops.** §5.7 finds the entry to retire in
   §0's capped output, so a bare truncation count would let a file over the cap
   grow forever.
4. **An unreadable harness file must say UNKNOWN**, never "nothing learned so
   far" — the latter sends a loop to re-diagnose from scratch, which is the
   exact failure the feature exists to end.
5. **One review finding rejected with evidence:** the commit subject's project
   token stays the lower-cased display name, because the journal publisher
   already does that and `origin/main` carries `chore(rafa): journal software
   factory #164`.
6. **No numbered prompt section added or renumbered** — `PROMPT_SECTIONS` and
   `PHASE_SECTIONS` key on those numbers.
7. **Role prompts deliberately untouched**, per the issue's Out of scope.
